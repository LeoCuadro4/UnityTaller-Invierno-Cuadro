# Escena Invernal de Rescate – Unity 3D

## Descripción
Proyecto desarrollado en Unity 3D como parte del Taller de Laboratorio. Consiste en una escena invernal donde un vehículo policial se encuentra parcialmente enterrado en la nieve, con sus luces de emergencia y efectos de partículas.

## Características
- Terreno nevado con relieve y textura.
- Iluminación ambiental nocturna.
- Luces de emergencia rojas y azules controladas mediante código.
- Sistema de partículas para simular la caída de nieve.
- Sistema de partículas para representar el humo del escape del vehículo.

## Tecnologías
- Unity 6.6 (6000.6.3f1)
- C#
- Universal Render Pipeline (URP)
